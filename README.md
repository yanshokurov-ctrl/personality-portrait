# Портрет личности

Программный модуль для определения личностных характеристик человека на основе
методически подготовленных вопросов и ключей (20 методик). В дальнейшем модуль
планируется интегрировать в систему построения индивидуальной образовательной траектории.

## Стек

- Python 3.12+
- Flask — веб-интерфейс
- pytest — тесты
- Методики хранятся в JSON (`app/methodologies/data/`)

## Структура проекта

```
app/
  engine/          — Движок опроса: показ вопросов, приём ответов, группировка
  collector/       — Сборщик результатов: итоговый отчёт «Портрет личности»
  methodologies/   — Базовый класс методики и обработка ответов
    data/          — Вопросы и ключи методик (по одному JSON на методику)
  validator/       — Проверка целостности модуля перед запуском
  web/             — Интерфейс: экран опроса и экран результатов
tests/             — Автотесты
docs/              — Документация команды
```

## Запуск (для разработчиков)

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows
pip install -r requirements.txt
pytest
```
