# Примеры отчётов «Портрет личности»

Примеры получены запуском модуля на методиках-заглушках (балл = сумма ответов 1–5).
Формат структуры описан в [architecture.md](architecture.md#формат-отчёта-портрет-личности).

Статусы результата методики:

| `status` | Значение | Что видит пользователь |
|----------|----------|------------------------|
| `ok` | Методика обработана | Балл, уровень, интерпретация |
| `missing` | Нет ни одного ответа на вопросы методики | «Вы не ответили на вопросы этой методики» |
| `error` | Методика не загрузилась, упала или вернула результат не по контракту | «Результат по методике временно недоступен» |

## 1. Полное прохождение

Ответы: методика 1 — 5, 4, 5; методика 2 — 2, 3, 2.

```json
{
  "results": [
    {
      "methodology_id": "m01",
      "name": "Оценка особенностей личности",
      "status": "ok",
      "scales": [
        {
          "scale_id": "total",
          "name": "Общий балл",
          "score": 14,
          "level": "high",
          "interpretation": "Высокий уровень выраженности характеристики."
        }
      ],
      "message": ""
    },
    {
      "methodology_id": "m02",
      "name": "Индекс устойчивости идентичности",
      "status": "ok",
      "scales": [
        {
          "scale_id": "total",
          "name": "Общий балл",
          "score": 7,
          "level": "medium",
          "interpretation": "Средний уровень выраженности характеристики."
        }
      ],
      "message": ""
    }
  ],
  "created_at": "2026-10-20T14:05:00"
}
```

Как это выглядит для пользователя:

```
============================================================
ПОРТРЕТ ЛИЧНОСТИ
Дата: 2026-10-20T14:05:00
============================================================

1. Оценка особенностей личности
   Общий балл: 14, уровень: высокий
   Высокий уровень выраженности характеристики.

2. Индекс устойчивости идентичности
   Общий балл: 7, уровень: средний
   Средний уровень выраженности характеристики.

Итого: обработано 2, без ответов 0, с ошибкой 0 из 2
```

## 2. Пропуск и остановка на середине

Ответы: методика 1 — 4, пропуск, 5; на методике 2 пользователь завершил опрос.
Методика 1 посчитана по имеющимся ответам (4 + 5 = 9), у методики 2 — `missing`.

```json
{
  "results": [
    {
      "methodology_id": "m01",
      "name": "Оценка особенностей личности",
      "status": "ok",
      "scales": [
        {
          "scale_id": "total",
          "name": "Общий балл",
          "score": 9,
          "level": "medium",
          "interpretation": "Средний уровень выраженности характеристики."
        }
      ],
      "message": ""
    },
    {
      "methodology_id": "m02",
      "name": "Индекс устойчивости идентичности",
      "status": "missing",
      "scales": [],
      "message": "Нет ответов на вопросы методики"
    }
  ],
  "created_at": "2026-10-20T14:05:00"
}
```

```
1. Оценка особенностей личности
   Общий балл: 9, уровень: средний
   Средний уровень выраженности характеристики.

2. Индекс устойчивости идентичности
   Вы не ответили на вопросы этой методики.

Итого: обработано 1, без ответов 1, с ошибкой 0 из 2
```

## 3. Сбой методик

Методика 2 падает при подсчёте, методика 3 не смогла выдать вопросы.
Методика 1 при этом обработана нормально — ошибка одной методики не ломает отчёт.

```json
{
  "results": [
    {
      "methodology_id": "m01",
      "name": "Оценка особенностей личности",
      "status": "ok",
      "scales": [
        {
          "scale_id": "total",
          "name": "Общий балл",
          "score": 9,
          "level": "medium",
          "interpretation": "Средний уровень выраженности характеристики."
        }
      ],
      "message": ""
    },
    {
      "methodology_id": "m02",
      "name": "Индекс устойчивости идентичности",
      "status": "error",
      "scales": [],
      "message": "ошибка при обработке: RuntimeError('сбой методики')"
    },
    {
      "methodology_id": "m03",
      "name": "Критическое мышление",
      "status": "error",
      "scales": [],
      "message": "Вопросы методики не загрузились: не удалось получить вопросы: RuntimeError('вопросы недоступны')"
    }
  ],
  "created_at": "2026-10-20T14:05:00"
}
```

```
1. Оценка особенностей личности
   Общий балл: 9, уровень: средний
   Средний уровень выраженности характеристики.

2. Индекс устойчивости идентичности
   Результат по методике временно недоступен.

3. Критическое мышление
   Результат по методике временно недоступен.

Итого: обработано 1, без ответов 0, с ошибкой 2 из 3
```

Поле `message` предназначено для разработчиков и валидатора; пользователю показывается
только понятный текст.
