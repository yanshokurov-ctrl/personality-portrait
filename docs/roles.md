# Роли и состав команды

Срок распределения ролей: **12.10.2026**. Состав команды: 10 человек.

| № | ФИО | Роль | Зона ответственности (этап 1) | Контакт |
|---|-----|------|-------------------------------|---------|
| 1 |  | Разработчик (основной) | Архитектура, контракты, ревью, интеграция |  |
| 2 |  | Разработчик 1 | Движок: показ вопросов, навигация вперёд/назад, порядок блоков |  |
| 3 |  | Разработчик 2 | Движок: приём ответов, группировка по методикам, пропуски |  |

| 5 |  | Тестировщик 1 | Тестовые сценарии движка (полное прохождение, пропуски, остановка) |  |

| 7 |  | Тестировщик 3 | Тестирование сборщика: потери, дубликаты, отсутствующие результаты |  |
| 8 |  | Разработчик документации 1 | Описание API движка |  |
| 9 |  | Разработчик документации 2 | Инструкция «Как подключить методику», сценарии использования |  |
| 10 |  | Разработчик документации 3 | Описание формата отчёта «Портрет личности», протоколы встреч |  |

## Обязанности ролей (по заданию)

| Роль | Кол-во | Обязанности |
|------|--------|-------------|
| Разработчик (основной) | 1 | Проектирование архитектуры решения внутри команды, написание ключевой логики |
| Разработчик | 3 | Написание функционального кода по задачам, поставленным основным разработчиком |
| Тестировщик | 3 | Проверка работоспособности кода, поиск ошибок, составление тестовых сценариев, проверка соответствия задаче |
| Разработчик документации | 3 | Ведение внутренней документации команды, описание работы модуля, подготовка отчётности |

> Зоны ответственности на этапах 2 и 3 будут распределены в начале каждого этапа.
