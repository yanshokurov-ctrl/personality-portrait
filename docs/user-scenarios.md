# Сценарии использования

Как пользователь проходит опрос от начала до конца. До этапа 3 опрос проходится
в консоли (`python -m app.demo`), потом — в веб-интерфейсе по тем же правилам.

## Сценарий 1. Полное прохождение

1. Пользователь запускает опрос. Вопросы идут блоками: сначала все вопросы методики 1,
   потом методики 2 и т. д. до методики 20.
2. На экране — номер вопроса («Вопрос 3 из 60»), текст и варианты ответа.
3. Пользователь вводит номер варианта, программа переходит к следующему вопросу.
4. После последнего вопроса показывается отчёт «Портрет личности»: по каждой методике —
   балл, уровень (низкий / средний / высокий) и текстовое пояснение.

## Сценарий 2. Исправление ответа

1. Пользователь понял, что ошибся в предыдущем вопросе, и вводит «н» (назад).
2. Программа показывает предыдущий вопрос, пользователь отвечает заново.
3. Новый ответ заменяет старый, опрос продолжается.

## Сценарий 3. Пропуск вопроса

1. Пользователь не хочет отвечать и вводит «п» (пропустить).
2. Вопрос считается пропущенным, программа переходит дальше.
3. Методика считает результат по тем ответам, что есть.
4. Если пропущены все вопросы методики, в отчёте пишется
   «Вы не ответили на вопросы этой методики».

Обязательный вопрос пропустить нельзя — программа попросит ответить.

## Сценарий 4. Остановка на середине

1. Пользователь вводит «в» (завершить), не дойдя до конца.
2. Вопросы, до которых он не дошёл, считаются пропущенными.
3. Показывается отчёт: по пройденным методикам — результаты, по остальным —
   «Вы не ответили на вопросы этой методики».

## Сценарий 5. Неверный ввод

1. Пользователь вводит то, чего нет среди вариантов (например, «9» или «abc»).
2. Программа сообщает об ошибке и показывает тот же вопрос снова. Ответ не сохраняется.

## Сценарий 6. Сбой методики

1. Одна из методик не смогла выдать вопросы или посчитать результат.
2. Опрос всё равно проходится до конца по остальным методикам.
3. В отчёте у этой методики написано «Результат по методике временно недоступен».

## Подсказка по клавишам

| Ввод | Действие |
|------|----------|
| число | ответить (для нескольких вариантов — числа через пробел или запятую) |
| `п` или `s` | пропустить вопрос |
| `н` или `b` | вернуться к предыдущему вопросу |
| `в` или `q` | завершить опрос и показать отчёт |
